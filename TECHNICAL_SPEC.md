# Техническое задание

## Версии ПО
- Java: 21
- Spring Boot: 3.2.x
- JavaFX: 21
- SQLite JDBC: 3.45.x
- Maven: 3.9.x

## Точные требования к функционалу
1. Вход в систему (аутентификация по логину/паролю)
2. Просмотр списка спутниковых систем с фильтрацией
3. Просмотр списка радиоизлучений с фильтрацией по частоте
4. Создание/редактирование записей (по ролям)
5. Комментирование записей (технические/информационные)
6. История изменений для каждой записи
7. Согласование изменений от операторов
8. Управление пользователями (только админ)

## Список экранов приложения
1. Экран логина
2. Главный дашборд
3. Список спутниковых систем
4. Список радиоизлучений
5. Детальная карточка излучения
6. Экран согласований
7. Экран истории изменений
8. Экран управления пользователями

## Поля радиоизлучения (точные)
- Название (обязательное, до 200 символов)
- Код (обязательное, до 50 символов, уникальное в рамках спутника)
- Частота МГц (обязательное, число)
- Полоса пропускания кГц
- Тип модуляции
- Мощность дБм
- Поляризация
- Тип сигнала
- Технические параметры (свободная форма)
- Дата измерения
- Место измерения
- Приоритет
- Классификация
- Примечания
