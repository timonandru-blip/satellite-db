# Satellite Radio Emission Database — Project Context

## О проекте
Десктопное приложение для работников космической отрасли, хранящее базу данных 
спутниковых систем и параметров радиоизлучений. Работает **полностью offline**, 
без доступа к интернету.

## Ключевые характеристики
- **Тип**: Десктопное приложение (локальное)
- **Пользователи**: 3 одновременных (Админ, Начальник смены, Оператор)
- **Объём данных**: Средний (100K - 10M записей)
- **Интернет**: Отсутствует (полностью offline)
- **Масштабируемость**: Нужна (архитектурно заложена)

## Технологический стек
- **Backend**: Java 21 + Spring Boot 3.x
- **Frontend**: JavaFX 21
- **Database**: SQLite (локальный файл)
- **ORM**: Spring Data JPA + Hibernate
- **Migrations**: Flyway
- **Build**: Maven

## Роли пользователей
| Роль | Возможности |
|------|-------------|
| **ADMIN** | Полные права + управление пользователями |
| **SHIFT_SUPERVISOR** | CRUD записей + согласование изменений операторов |
| **OPERATOR** | Создание записей + запросы на изменение/удаление |

## Ключевые сущности
- `users` — пользователи системы
- `satellite_systems` — спутниковые системы
- `radio_emissions` — параметры радиоизлучений
- `comments` — технические и информационные комментарии
- `audit_log` — история всех изменений
- `pending_changes` — запросы на согласование

## Жёсткие ограничения
1. Никаких внешних HTTP-запросов
2. Никаких облачных сервисов
3. Все данные — только локально
4. История изменений обязательна для всех операций
5. Оператор не может изменять/удалять записи напрямую

## Приоритеты
1. Производительность (быстрый поиск и фильтрация)
2. Масштабируемость (архитектурная готовность к росту)
3. Безопасность (разграничение прав, аудит)
4. Документируемость (автогенерация)
